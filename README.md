`life/` un `#materiali/` satur darbus, kuriem mapēs nav norādīts konkrēts autors. Labirintu mapē `Nezinams` ir arī neidentificēta autora darbs. Testa boti un `Test1`–`Test4` nav uzskaitīti kā studenti.
